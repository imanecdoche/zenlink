Kabel untuk live streaming

Resolusi native penuh dengan bitrate tinggi (12–30 Mbps), cara yang sama dengan TikTok LIVE Studio.

Kontrol penuh

Mouse jadi sentuhan, ketik dengan keyboard PC, plus Home, App Switcher, Notifikasi, Pusat Kontrol dan tombol.

Suara ikut, sinkron

Suara perangkat keluar di speaker PC dengan lip sync, dan buffer anti-patah untuk Wi-Fi.

Statistik live

FPS, delay video dan delay audio langsung di samping nama perangkat. Pas untuk streamer.

Salin teks dari layar

Alt+C membaca teks di layar perangkat (OCR) ke clipboard PC; Alt+V mengetik isi clipboard ke perangkat.

Stealth dim

Alt+D meredupkan layar perangkat ke 0% sementara gambar di PC tetap terang.

Layar penuh & putar

F11 untuk layar penuh, Alt+H untuk memutar gambar. Jendela menyesuaikan bentuk perangkat.

Untuk live streaming

ZenLink Studio · Kabel

USB · driver libusb0 (dipasang setelah kamu setuju)
  • Resolusi native penuh layar perangkat
  • H.264 bitrate tinggi, hingga ~56 fps
  • Delay sangat rendah
  • Gambar dan suara saja
Tanpa kabel

ZenLink Studio · Wi-Fi

AirPlay Screen Mirroring · tanpa driver
  • Stream asli perangkat, tanpa encode ulang
  • Hingga 3108×2160 di iPad, ~16 ms
  • Panduan langsung di layar
  • Gambar dan suara saja

Kemungkinan muncul peringatan.

ZenLink adalah aplikasi baru dari satu developer independen dan belum ditandatangani. Windows belum sering melihatnya, jadi muncul pesan hati-hati. Begini cara melewatinya.

Di browser

"ZenLink-Setup.exe jarang diunduh"

  1. Di daftar unduhan, klik … di samping file.
  2. Pilih Simpan (Keep).
  3. Klik Tampilkan lainnya, lalu Tetap simpan.
Saat dibuka

"Windows melindungi PC Anda"

  1. Klik Info selengkapnya.
  2. Klik Tetap jalankan.
  3. Ikuti installer. ZenLink terbuka dan menyiapkan semuanya.

Kenapa bisa dipercaya

  • Open source. Seluruh kode ada di GitHub (GPL-3.0); siapa pun bisa memeriksa dan membangunnya sendiri.
  • Tanpa hak admin, tanpa yang tersembunyi. Terpasang untuk user kamu saja dan bersih saat di-uninstall. Driver USB dan aturan firewall hanya dipasang setelah kamu setuju.
  • Data tetap di PC kamu. Tanpa akun, tanpa pelacakan. Gambar dan suara hanya lewat kabel atau jaringan lokal.
  • Keyboard, dijelaskan. ZenLink hanya meneruskan ketikan ke perangkat saat jendelanya aktif di mode Apple Driver, dan tidak pernah merekamnya.

Tanya jawab

Apakah ZenLink gratis?

Ya. ZenLink gratis dan open source (GPL-3.0). Kalau terbantu, kamu bisa mendukung lewat Sociabuzz.

Perangkat dan versi iOS apa yang didukung?

iPhone dan iPad. Mode Apple Driver butuh iOS 17 atau lebih baru dengan Developer Mode, plus Apple Devices atau iTunes di PC. ZenLink Studio (kabel atau AirPlay) tidak butuh Developer Mode.

ZenLinkStudio tidak muncul di Pencerminan Layar?

Pastikan PC dan perangkat ada di Wi-Fi yang sama, lalu izinkan aturan firewall "ZenLink (AirPlay)" saat diminta. Izinnya hanya untuk jaringan lokal dan kamu yang menyetujuinya.

Tersambung lewat kabel tapi layar tidak muncul?

Restart iPhone/iPad (matikan lalu nyalakan), buka kuncinya, lalu tekan Mulai lagi. ZenLink juga akan menyarankan ini.

Antivirus menandai installer. Apakah aman?

ZenLink belum ditandatangani, jadi beberapa antivirus berhati-hati dengan file baru. Unduh hanya dari halaman ini atau GitHub, cocokkan SHA-256-nya, dan kalau ragu kamu bisa membangunnya sendiri dari kode sumber.

Bagaimana cara update?

Unduh versi terbaru dari halaman ini dan jalankan installer-nya; pengaturan kamu tetap tersimpan. Versi Portable cukup diganti dengan file yang baru.

Bagaimana cara keluar sepenuhnya?

Klik ^ di taskbar, klik kanan ikon ZenLink, lalu pilih Keluar ZenLink. Tombol tutup hanya menyembunyikannya ke tray kalau "Tutup ke tray" aktif.

Privasi

ZenLink tidak mengumpulkan data pribadi dan tidak punya analitik. Gambar, suara, teks dan ketikan tetap di PC kamu; pengaturan disimpan di folder user kamu.

Passcode perangkat (untuk Alt+U) dienkripsi dengan Windows DPAPI dan hanya bisa dibuka oleh akun Windows kamu. OCR berjalan di PC lewat Windows, tanpa internet.

Halaman ini hanya mengambil versi terbaru dan jumlah unduhan dari GitHub. Tidak ada cookie dan tidak ada pelacakan.
