Privacy Policy

Last updated: 8 November 2026 · Applies to ZenLink for Windows (Microsoft Store, installer, portable and source editions).

Summary

ZenLink collects no personal data. It has no account, no analytics, no advertising and no tracking. The developer receives nothing from the app.

What stays on your PC

  • The picture, sound, text and keystrokes of your phone or tablet travel only between the device and your PC, over the USB cable or your local Wi-Fi network. They are not sent to the internet.
  • Settings and the list of your devices are stored in your Windows user folder.
  • The device passcode (optional, for the Alt+U unlock shortcut) is encrypted with Windows DPAPI. Only your Windows account can open it.
  • Text recognition (OCR) runs on your PC through Windows, offline.
  • Log files are written to your user folder for troubleshooting. They stay there unless you choose to share them.

Network connections

  • Local network: to find and connect to your own devices (AirPlay, ZenLink Studio over Wi-Fi, Android over Wi-Fi via adb).
  • Updates: the Microsoft Store edition is updated by the Microsoft Store and does not check for updates itself. The installer and portable editions ask GitHub (api.github.com) for the latest release when you check for updates. GitHub sees your IP address, as with any web request; ZenLink sends no personal data.
  • Manual (source) edition only: on first start it downloads Google's official Android platform-tools (adb) from dl.google.com.

Third parties

Android mirroring uses the open-source scrcpy server by Genymobile and Google's adb, both running locally. Purchases in the Microsoft Store are handled by Microsoft under the Microsoft Privacy Statement; the developer only receives aggregated sales reports.

Children

ZenLink does not collect data from anyone, including children.

Contact

Questions: open an issue at github.com/zenvyzenshiro/zenlink. The source code is public (GPL-3.0), so anyone can check these statements.

Kebijakan Privasi

Terakhir diperbarui: 8 November 2026 · Berlaku untuk ZenLink untuk Windows (edisi Microsoft Store, installer, portable dan source).

Ringkasan

ZenLink tidak mengumpulkan data pribadi. Tanpa akun, tanpa analitik, tanpa iklan dan tanpa pelacakan. Pengembang tidak menerima apa pun dari aplikasi.

Yang tetap di PC kamu

  • Gambar, suara, teks dan ketikan HP atau tablet kamu hanya lewat antara perangkat dan PC, melalui kabel USB atau Wi-Fi lokal. Tidak dikirim ke internet.
  • Pengaturan dan daftar perangkat disimpan di folder user Windows kamu.
  • Passcode perangkat (opsional, untuk Alt+U) dienkripsi dengan Windows DPAPI. Hanya akun Windows kamu yang bisa membukanya.
  • OCR berjalan di PC lewat Windows, tanpa internet.
  • File log ditulis ke folder user kamu untuk pemecahan masalah, dan tetap di sana kecuali kamu sendiri membagikannya.

Koneksi jaringan

  • Jaringan lokal: untuk menemukan dan menyambung ke perangkatmu sendiri (AirPlay, ZenLink Studio lewat Wi-Fi, Android lewat Wi-Fi dengan adb).
  • Update: edisi Microsoft Store diperbarui oleh Microsoft Store dan tidak mengecek update sendiri. Edisi installer dan portable bertanya ke GitHub (api.github.com) soal rilis terbaru saat cek update. GitHub melihat alamat IP kamu seperti permintaan web biasa; ZenLink tidak mengirim data pribadi.
  • Khusus edisi Manual (source): saat pertama jalan, mengunduh platform-tools Android (adb) resmi Google dari dl.google.com.

Pihak ketiga

Mirror Android memakai server scrcpy open source dari Genymobile dan adb dari Google, keduanya berjalan lokal. Pembelian di Microsoft Store diurus Microsoft sesuai Microsoft Privacy Statement; pengembang hanya menerima laporan penjualan agregat.

Anak-anak

ZenLink tidak mengumpulkan data dari siapa pun, termasuk anak-anak.

Kontak

Pertanyaan: buka issue di github.com/zenvyzenshiro/zenlink. Kode sumbernya publik (GPL-3.0), jadi siapa pun bisa memeriksa pernyataan ini.
